# Backend

FastAPI + PostgreSQL (pgvector). Wyszukiwanie semantyczne ogłoszeń i filtry
nasłuchiwania, które powiadamiają o pasujących przedmiotach.

- [`docs/uruchomienie.md`](docs/uruchomienie.md) – jak postawić projekt
  lokalnie, sprawdzić, że działa, i jak go zatrzymać.
- [`docs/stan-obecny.md`](docs/stan-obecny.md) – co jest faktycznie
  zbudowane, jak działa dopasowanie i czego brakuje względem specyfikacji.
- [`../README.md`](../README.md) – specyfikacja docelowa. Opisuje stan
  zamierzony, nie stan kodu.
